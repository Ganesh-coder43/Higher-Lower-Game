# 🎯 Higher Lower Game

An interactive command-line Python game where players compare two famous personalities and guess who has more Instagram followers. Test your knowledge, build your winning streak, and achieve the highest score!

---

## 📖 About the Project

This project is a Python implementation of the popular **Higher Lower** game. Players are presented with two celebrities and must guess which one has more Instagram followers. The game continues until an incorrect guess is made.

While inspired by the original game concept, this version includes several custom features and improvements that I implemented to make the gameplay more engaging and balanced.

---

## ✨ Features

- 🎮 Interactive command-line gameplay
- 👥 Large custom dataset of celebrities from around the world
- 🌍 Includes:
  - Actors & Actresses
  - Cricketers
  - Footballers
  - Singers
  - Entrepreneurs
  - Politicians
  - Athletes
  - YouTubers
- 📈 Score tracking
- 🔄 Prevents duplicate celebrity comparisons
- 🎯 Custom balancing feature that refreshes celebrities after every two correct answers
- 🔁 Play Again option
- ✅ User input validation

## 🎮 How to Play

1. Two famous personalities are displayed.
2. Compare their professions and countries.
3. Guess who has more Instagram followers.
4. Type **A** or **B**.
5. Each correct answer increases your score.
6. The game ends when you make an incorrect guess.
7. Choose whether to play again after the game ends.
